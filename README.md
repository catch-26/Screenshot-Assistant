## Install

Download the APK from [Releases](https://github.com/user-mb/Screenshot-Assistant/releases). Requires Android 14 or newer.

## Setup

1. Install the app.
2. Set it as the digital assistant app: `Settings` > `Apps` > `Default apps` > `Digital assistant app`.
3. Trigger the assistant, then crop, draw and share.
